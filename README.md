# Projects — David Sabalete

A showcase of projects built by David Sabalete, Senior Full Stack Developer and Vue.js expert based in Barcelona.

## Overview

This site displays a curated selection of web applications and tools built using modern technologies including Vue.js, Nuxt, React, and more.

## Features

- **Responsive grid layout** — adaptively displays project cards across all screen sizes
- **Dark mode support** — automatic theme switching via `prefers-color-scheme`
- **Tech stack tags** — each project is tagged with its core technologies
- **Live links and repositories** — direct links to deployed apps and source code

## Project Stack

- **Frontend:** Vue 3, TypeScript, Vite, Nuxt 4, React 19, TailwindCSS
- **Backend:** Node.js, Firebase, Supabase, Netlify Functions
- **APIs:** EODHD, Chatbot/AI integrations

## Getting Started

```bash
# Install dependencies
npm install

# Development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
